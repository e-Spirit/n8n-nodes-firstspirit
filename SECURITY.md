# Security Policy

## MIT License Users

- The maintainers do not provide a formal SLA for security issues under the MIT License.
- Releases prioritize new functionality and include fixes for known security vulnerabilities at release time. The maintainers do not guarantee a fixed release schedule.
- Version Support: Security patches are only provided for the latest release version.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub instead: open the **Security** tab of this repository and choose
**Report a vulnerability**, or use
[this link](https://github.com/e-Spirit/n8n-nodes-firstspirit/security/advisories/new). Include the
affected version, the steps to reproduce the problem and its impact. Reports stay private between you
and the maintainers until a fix is available.
